# Portfólio de João Victor Lopes

Portfólio de João Victor Lopes, desenvolvedor full-stack. Reúne projetos de interfaces web, aplicações full-stack e APIs REST, com destaque para o Velynto, um CRM para clínicas com gestão de equipes, agenda e atendimento via WhatsApp em ambiente de teste.

O site foi construído em HTML, CSS e JavaScript. A página é responsiva, oferece filtros por tipo de projeto e inclui animações de rolagem que respeitam a preferência de movimento reduzido do sistema.
